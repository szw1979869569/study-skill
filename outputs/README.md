# Outputs

This area is for reviewed, non-sensitive, reproducible outputs only. Generated files should first go to `outputs/generated/` or another ignored staging location. Commit an output only after scientific review, privacy/disclosure review, and license confirmation.

Create a record from `result-record-template.md` for each release. Do not commit raw data, participant listings, small or disclosive cells, identifiable images, logs, credentials, or restricted materials.
